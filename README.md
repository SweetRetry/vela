# VELA

> 图像是正面，prompt 是背面。

VELA 是一份 AI 视觉作品档案。

每件作品都将最终图像与促成它的原始生成指令并置保存：正面观看画面，背面阅读构图、
材质、光色与叙事意图。这里记录的不只是结果，也包括一幅图像如何被描述、约束与生成。

[进入 VELA](https://sweetretry.github.io/vela/)
